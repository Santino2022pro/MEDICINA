# Entregable 3 — Mapa de secuencias Morph

Cada secuencia fue construida duplicando la diapositiva anterior: los objetos conservan **el mismo nombre** (prefijo `!!`, coincidencia forzada de Morph) y solo cambian posición, escala, rotación o color; los objetos nuevos se agregan encima.

La transición **Transformación (Morph)** ya quedó aplicada en la segunda y siguientes diapositivas de cada secuencia, con respaldo «Desvanecer» para versiones de PowerPoint sin Morph. Si preferís aplicarla manualmente, seleccioná esas diapositivas → *Transiciones → Transformación → Opciones: Objetos*.
